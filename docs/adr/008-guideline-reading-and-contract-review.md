# ADR-008: 지침 재조회 조건과 전체 검증 전 계약 검토

- 상태: Accepted
- 기준일: 2026-09-12
- 관계: [ADR-007](007-commit-checkpoints.md)의 단위별 검토를 보완하고 [루트 문서 탐색 원칙](../../AGENTS.md#읽기-경로)을 구체화합니다. 기존 결정의 대체는 없습니다.

## 배경

지침을 큰 출력으로 반복 조회해도 적용할 조건을 놓칠 수 있습니다. 이미 알려진 계약 규칙의 누락을 전체 검증 후 발견하면 수정과 전체 검증을 다시 수행해야 합니다.

## 결정

- 작업에 필요한 지침을 출력 한도 안에서 읽고 핵심 조건을 대화나 임시 메모에 재사용합니다. 잘린 출력은 누락 구간만 조회하며, 문서 변경·범위 확대·구체적인 불확실성이 있을 때 필요한 부분을 재확인합니다. 영구적인 읽기 기록은 만들지 않습니다.
- 각 변경 단위의 집중 검사와 diff 검토에서 적용 지침 및 계약의 선언·구현·호출부·테스트를 대조합니다. 계약 불일치는 관련 선언을 함께 비교해 원인을 수정한 뒤 집중 검사합니다.
- 모든 단위의 검토와 알려진 수정을 마친 뒤 전체 검증합니다. 전체 검증에서 새로 발견한 문제의 수정·재검증 의무는 유지합니다.

절차의 원본은 [읽기 경로](../../AGENTS.md#읽기-경로), [커밋 체크포인트](../conventions/github-workflow.md#작업-중-커밋-체크포인트), [테스트 규칙](../conventions/testing.md)입니다.

## 영향과 검증

문서 재조회와 뒤늦은 계약 수정에 따른 재작업을 줄이는 절차이며, 새 승인 단계나 검사 횟수 제한을 추가하지 않습니다. 실제 절감량을 보장하지 않습니다. 단위별 집중 검사·커밋, 전체 검증과 DB·푸시 승인 경계는 유지합니다.

문서 링크·앵커, 원본과 온보딩 순서의 일관성, ADR의 양방향 연결과 Accepted 상태, `git diff --check`로 확인합니다. 실행 코드·빌드·CI 설정은 변경하지 않습니다.
